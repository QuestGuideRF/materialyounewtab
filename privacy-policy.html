Политика конфиденциальности для MYNT: Материалы Новая вкладка

Introduction

"MYNT: Material You New Tab" is an open-source extension designed to enhance the appearance of your browser’s default home page and new tab. It was originally developed as a personal project using HTML, CSS, and JavaScript. Due to positive feedback, it was later made available on both the Firefox and Chrome Web Stores.

Вклад сообщества

Since its release, talented developers from the community have contributed to improving the extension through GitHub. These contributors have added new features and fixed bugs, making the extension even better. Each pull request is carefully reviewed, tested, and verified to ensure it meets our standards before being merged.

Сбор данных и разрешения

MYNT: Новая вкладка Material You отдает приоритет вашей конфиденциальности и ориентирована исключительно на обеспечение лучшего просмотра. опыт. Это расширение делает не собирать, store, или share любые личные данные. Вся обработка выполняется локально в вашем браузере. Никакой аналитики, включены сценарии отслеживания или системы удаленной регистрации.

Permissions

Мы запрашиваем только минимальные разрешения, необходимые для обеспечения богатого и динамичного просмотра. Ниже приведен разбивка используемых разрешений и для чего они нужны:

  • Search: Включает интеграцию с поисковой системой браузера по умолчанию.
  • Bookmarks (необязательно): если предоставлено, позволяет дополнительно отображать ваши закладки непосредственно на новая вкладка.
  • Favicon (optional): Used to retrieve bookmark favicons from the browser cache. It only returns icons the browser already has cached and does not expose browsing history or page content.

API браузера

  • Распознавание речи (API веб-речи): Enables voice search. Microphone access is triggered only when the mic icon is clicked and is handled entirely by your browser. No voice data is collected or stored.
  • Geolocation: Used to improve weather accuracy. Access is browser-managed and is not tracked or shared.

Внешние API

Для улучшения пользовательского опыта мы используем следующие внешние сервисы:

  • Поисковые предложения:
    • Google: https://www.google.com/complete/search?client=*
    • DuckDuckGo: https://duckduckgo.com/ac/?q=*
    • Brave: https://search.brave.com/api/suggest?q=*
    • Wikipedia: https://*.wikipedia.org/w/api.php?action=opensearch&search=*

    Они используются для предоставления предложений по автозаполнению при вводе в строку поиска. Вы можете контролировать к каким сайтам расширение может получить доступ, в настройках вашего браузера.

  • Определение местоположения (IPinfo):
    • https://ipinfo.io/json – fetches approximate city-level location based on your IP for local weather display.
  • Обновления погоды (WeatherAPI):
    • https://api.weatherapi.com/v1/forecast.json?key=* – извлекает ежедневные прогнозы на основе от вашего местоположения и языковых предпочтений.
    • https://api.weatherapi.com/v1/search.json?key=* – используется для получения местоположения предложения при поиске города.
  • Случайные обои (Посмотрите фото):
    • https://picsum.photos/1920/1080 – используется для получения случайных изображений высокого качества.
  • Извлечение значков (API Favicon от Google):
    • https://s2.googleusercontent.com/s2/favicons*
    • https://www.google.com/s2/favicons*
    Они используются для получения значков веб-сайтов для ярлыков и закладок.

Прокси-сервер (необязательно)

MYNT: Новая вкладка Material You включает дополнительную функцию прокси, которая отключено по умолчанию. Эту функцию можно использовать для обхода ограничений CORS при получении поисковых предложений.

Для пользователей, которые хотят включить эту функцию, мы очень рекомендую хостинг свой собственный прокси-сервер для сохранения полного контроля и обеспечения максимальной конфиденциальности.

If enabled and left at the default setting, search suggestion requests will be routed through the public proxy at: https://mynt-proxy.rhythmcorehq.com.

Прозрачность и безопасность

Хотя мы стремимся обеспечить безопасность нашего кода, мы признаем, что ни один проект не застрахован от потенциальных проблемы. В редких случаях непреднамеренный код или ошибки могут быть внесены в результате внесения изменений. Мы поощряем пользователи могут просматривать исходный код непосредственно на GitHub для душевного спокойствия. Пожалуйста, используйте это расширение только тогда, когда вас полностью устраивает его содержимое.
