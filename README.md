# MYNT: Material You New Tab

**MYNT: Material You New Tab** — это расширение для браузера, которое персонализирует страницу новой вкладки с настраиваемыми темами, быстрыми ссылками и полезными инструментами, при этом интегрируясь с вашей предпочитаемой поисковой системой.

## ✨ Особенности

- **Интегрированный поиск**: Поиск прямо со страницы новой вкладки с использованием предпочитаемой поисковой системы — Google, DuckDuckGo, Bing, Brave Search, YouTube, Wikipedia и других, с поддержкой голосового ввода
- **Настраиваемые темы**: Выберите из коллекции тем или используйте встроенный выбор цветов для соответствия вашему стилю
- **Обои**: Загрузите свои обои или включите ежедневные случайные изображения из Lorem Picsum
- **Часы и отображение времени**: Выберите между современными аналоговыми или цифровыми часами
- **Обновления погоды в реальном времени**: Просматривайте температуру, условия, влажность, ощущаемую температуру и значения максимальной/минимальной температуры. Поддерживает °C и °F с настройкой местоположения
- **Быстрые ярлыки**: Доступ к популярным платформам (YouTube, Email, WhatsApp и т.д.) или добавьте свои ярлыки для мгновенной навигации
- **Быстрые AI-ссылки**: Раскройте кнопку «Нейросети» в левом нижнем углу и откройте ChatGPT, Gemini, Claude или DeepSeek
- **YouTube Music и Яндекс Карты**: Используйте компактные ссылки в левом верхнем углу новой вкладки
- **Закладки в боковой панели**: Просматривайте, удаляйте и организуйте закладки в виде списка или сетки
- **Google Apps**: Быстрый запуск Gmail, Drive, Docs и других сервисов Google
- **Резервное копирование и сброс**: Сохраняйте или восстанавливайте настройки в любое время или сбросьте всё к значениям по умолчанию одним кликом
- **Поддержка языков**: Используйте расширение на предпочитаемом языке для лучшей доступности (31 язык)
- **Совместимость с браузерами**: Поддерживает все браузеры на базе Chromium, включая **Chrome**, **Edge**, **Brave** и **Opera**, а также браузеры на базе Firefox, такие как **Firefox** и **Zen**

## 🚀 Быстрый старт

### Установка

#### Для браузеров на базе Chromium (Chrome, Edge, Brave, Opera)

1. **Скачайте проект**:
       ```bash
   git clone <repository-url>
   ```
   Или скачайте ZIP-архив и распакуйте его

2. **Откройте страницу расширений**:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
   - Opera: `opera://extensions`

3. **Включите режим разработчика**:
   - Переключите переключатель **Режим разработчика** на странице расширений

4. **Загрузите расширение**:
   - Нажмите **Загрузить распакованное расширение**
   - Выберите папку с распакованным проектом

5. **Для Opera (дополнительно)**:
   > **Примечание**: Opera не поддерживает замену стандартной новой вкладки.
   > Этот метод только устанавливает расширение как стартовую страницу.

   - Перейдите в **Настройки**
   - Найдите раздел **При запуске**
   - Выберите **Открыть конкретную страницу или набор страниц** и добавьте новую страницу
   - Добавьте URL расширения (замените ID расширения на ваш):
   ```
   chrome-extension://<ваш-32-символьный-ID>/index.html
   ```

#### Для Firefox

1. **Скачайте проект** (см. выше)

2. **Подготовьте манифест**:
   - Удалите существующий файл `manifest.json`
   - Переименуйте `manifest(firefox).json` в `manifest.json`

3. **Загрузите временное дополнение**:
   - Перейдите в `about:debugging#/runtime/this-firefox`
   - Выберите **"Этот Firefox"**
   - Нажмите **Загрузить временное дополнение**
   - Выберите обновленный `manifest.json`

4. **Обновите домашнюю страницу**:
   - Откройте Firefox и получите UUID расширения (наведите курсор на кнопку новой вкладки или перейдите в `about:debugging#/runtime/this-firefox`)
   - Откройте **Настройки** и перейдите в раздел **Домашняя страница** (`about:preferences#home`)
   - В разделе **Домашняя страница и новые окна** выберите **Пользовательские URL...**
   - Вставьте следующий URL, заменив ID на ваш фактический UUID:
   ```
   moz-extension://<ваш-UUID>/index.html
   ```

5. **Для Zen Browser (дополнительно)**:
   - Откройте новую вкладку и перейдите в `about:config`
   - Найдите параметр `zen.urlbar.replace-newtab`
   - Установите его значение в **false**

### Настройка

После установки расширение готово к использованию. Вы можете настроить:

- **Тему и цвета**: Откройте настройки и выберите тему или создайте свою
- **Обои**: Загрузите свои изображения или включите случайные обои
- **Поисковую систему**: Выберите предпочитаемую поисковую систему из списка
- **Виджеты**: Включите или отключите часы, погоду, список задач и другие виджеты
- **Язык**: Выберите язык интерфейса из 31 доступного языка

### Использование

1. Откройте новую вкладку в браузере
2. Страница новой вкладки будет заменена на кастомную страницу MYNT
3. Используйте поисковую строку для поиска в интернете
4. Настройте виджеты и внешний вид через меню настроек
5. Добавьте свои ярлыки и закладки для быстрого доступа

## 🛠 Технологии

- **HTML5** — структура страницы
- **CSS3** — стилизация и анимации
- **JavaScript (ES6+)** — функциональность расширения
- **Browser Extension APIs** — интеграция с браузером
  - Chrome Extensions API (Manifest V3)
  - Firefox WebExtensions API (Manifest V2)
- **LocalStorage API** — хранение настроек локально
- **Weather API** — получение данных о погоде (требуется API ключ)

## 📝 Примечания

- Все настройки хранятся локально в браузере
- Для работы виджета погоды требуется API ключ от WeatherAPI (опционально)
- Расширение работает полностью офлайн после первоначальной загрузки
- Поддерживается режим инкогнито (split для Chrome, spanning для Firefox)
